1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
Open Chat is an autonomous multi-agent AI system combining persistent memory,
graph-based project knowledge (Graphify), reusable skills, and built-in 
security verification.

The platform provides a dual execution architecture:
- Simple Mode: High-speed, terminal-style direct inference with local Ollama
  (Qwen 2.5) for instant answers with zero orchestrator overhead.
- Complex Mode: Full multi-agent orchestration loop with RAG memory retrieval,
  parallel solving agents (Direct Solver, Critical Thinker, Research Synthesizer),
  Judge evaluation, verification review, and automatic knowledge graph writes.

2. COMPLETED IMPLEMENTATION & CONTRIBUTIONS
--------------------------------------------------------------------------------

[A] Backend Architecture (FastAPI + Python 3.12 + SQLite + Ollama):
  - Developed FastAPI asynchronous REST API endpoints:
      * /health (runtime health, provider status, active model)
      * /api/v1/tasks (synchronous & dual-mode execution engine)
      * /api/v1/projects (isolated project context management)
      * /api/v1/skills (24-skill categorized registry)
      * /api/v1/memory (SQLite persistent RAG memory & graph nodes)
  - Implemented the Multi-Agent Ensemble orchestration engine:
      * Autonomous Planner generating Step-by-Step DAG execution plans
      * Parallel Agent dispatching (Direct, Critical, and Research agents)
      * Automated Judge Rubric evaluating best candidate solutions
      * Verification loop preventing hallucinations & injection attacks
  - Created SQLite Graph Store (SQLiteGraphStore):
      * Seeded with 73 nodes and 95 relationship edges
      * Support for CONTAINS, CALLS, REQUIRES, and VERIFIED_BY edges
  - Configured Sandbox Tooling:
      * Safe math and expression calculator
      * SQLite memory search and retrieval tools
      * Web search research connector
      * REST API simulation and file system utilities

[B] Frontend Workspace (React 19 + TypeScript + Vite + Stratify UI):
  - Built Cyber-Deck / Stratify design system with rich dark/light UI tokens.
  - Interactive Dual-Mode Chat Stream:
      * Real-time progress stepper (Memory -> Parallel Agents -> Judge -> Write)
      * Instant Simple Mode toggle for low-latency queries
      * Collapsible DAG trace inspector and execution breakdowns
  - 3D & 2D Memory Graph Visualizer:
      * Force-directed 3D interactive knowledge graph rendering
      * Node category color coding, zoom, rotate, and node inspector panels
  - Project & Skills Configuration Manager:
      * Multi-project workspace switcher with isolated context state
      * 24-skill capability selector organized across 6 categories
  - Desktop integration with launcher scripts and real-time backend ping.

[C] System Engineering & Hardware Optimization:
  - Configured full local LLM execution pipeline with Ollama.
  - Optimized local model deployment on NVIDIA RTX 3050 (4GB VRAM):
      * Downloaded and integrated qwen2.5:3b (1.9GB) for ultra-fast GPU offloading.
      * Configured qwen2.5:7b (4.7GB) for advanced multi-agent reasoning tasks.
  - Relocated model storage and download path to secondary drive (E:\ollama\models)
    to prevent disk-space bottleneck on OS drive.
  - Created portable Windows automation launchers (start_app.bat, start_mock.bat).

4. HOW TO RUN THE PROJECT
--------------------------------------------------------------------------------
Option 1: Windows Batch Script
  Double-click `start_app.bat` in the root directory.

Option 2: Manual Start
  Backend:
    cd backend
    .\venv\Scripts\python.exe -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
  Frontend:
    cd frontend
    npm run dev -- --host 127.0.0.1 --port 5173

  Access:
    Web Interface: http://127.0.0.1:5173
    Backend Health: http://127.0.0.1:8000/health
    API Documentation: http://127.0.0.1:8000/docs
